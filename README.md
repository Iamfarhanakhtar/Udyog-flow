# UdyogFlow — Indian Business Compliance Operating System

> "From Business Idea to Government Approval — Simplified."

UdyogFlow is a modern compliance operating system designed for Indian MSMEs, startups, and founders. It turns statutory confusion across municipal, state, and central authorities (MCA, FoSCoS, BMC/MCGM, GSTN, MSME, Fire Brigade) into a deterministic, progressive business blueprint.

---

## Key Features

- **Guided Onboarding (`/onboarding`)**: Clean, focused wizard experience (free of dashboard clutter) with dynamic category and micro-niche mapping, physical jurisdiction identification (e.g. MCGM Ward K-West), entity architecture selection, and a 1.5s simulated compliance graph synthesis.
- **Business Blueprint (`/blueprint`)**: Real-time compliance graph with 10 structured mandates across 4 stages (Base Identity, Premises & Utilities, Operating Licenses, Tax & Finance). Includes progressive disclosure scrutiny inspector, readiness score ring (68%), and matched government schemes (PMEGP, PM MUDRA, Maharashtra MSME Electricity Duty Exemption).
- **Stitch Design Fidelity**: Faithful implementation of the Stitch **SIH** project design tokens ("Sovereign Blue & Slate Compliance System") using Plus Jakarta Sans and Inter.
- **Clean Decoupled Architecture**: Clean TypeScript domain models and `BusinessContext` with service abstraction layer ready for future FastAPI integration.

## Getting Started

### Prerequisites
- Node.js 18.18+ or 20+

### Installation
```bash
git clone https://github.com/Iamfarhanakhtar/Udyog-flow.git
cd Udyog-flow
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build & Lint
```bash
npm run lint
npm run build
npm run start
```
